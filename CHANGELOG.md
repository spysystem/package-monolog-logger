# Changelog

## 1.1.0

### Notes

- PHP 8.1 support dropped: requires PHP `~8.5.0`.
- Requires `spysystem/package-centralized-logger-data` `~1.1.0`.
- Removed `jetbrains/phpstorm-attributes` and `phpunit/phpunit` from `require-dev` (unused; no tests).
- Minimum versions raised to the first releases without PHP 8.5 deprecations: `monolog/monolog` `~3.11`
- Minimum version raised: `spysystem/code-helper` `~2.0.10`, the first release that installs on PHP 8.5
